# تقرير خيار OTP لاستعادة كلمة المرور — 2026-09-22

> **أمر المالك:** «نفذ خيار otp».
> **الحالة:** جوانب التطبيق منفذة ومنشورة ومتحقق منها حيًا (`b53ad590` + `69d56619`). تبقت خطوة واحدة بيد المالك: **لصق قالب البريد** (§2 أدناه — دقيقتان) ليظهر الرمز في الرسالة.

---

## 1. ماذا يضيف خيار OTP ولماذا هو الحل الجذري

ذراع الاستعادة السابقة (الرابط) تعتمد على كوكي PKCE verifier المكتوب في المتصفح الطالب حصرًا، وعلى كود يُستهلك بأول نقرة — لذا تفشل عبر الأجهزة ومع فاحصات روابط البريد (SafeLinks). **الرمز الرقمي لا يعتمد على ولا واحد منهما**:

| | رابط الاستعادة | رمز OTP (جديد) |
|---|---|---|
| يعمل من متصفح/جهاز آخر | ✗ | ✓ |
| يصمد لفاحص روابط البريد | ✗ (الكود يُستهلك مسبقًا) | ✓ (الفاحص لا يستهلك الرمز بالنقر) |
| يعمل بعد انتهاء جلسة المتصفح الأصلي | ✗ | ✓ |

المسار: المستخدم يدخل بريده + الرمز الستي في `/auth/reset?mode=code` ← `verifyOtp({ type: "recovery" })` تثبّت الجلسة في متصفحه الحالي ← يُسجّل كلمة المرور الجديدة مباشرة.

## 2. خطوة المالك الوحيدة: قالب البريد (دقيقتان)

**أين:** لوحة Supabase → مشروع alkemos → **Authentication → Emails → Templates → Reset Password (Recovery)**.

**الموضوع (Subject):**
```
رمز استعادة كلمة مرورك — Your Alkemos password reset code
```

**الجسم (Body — الصق كاملًا، مع ضبط Content Type = HTML):**
```html
<div style="font-family:Arial,Helvetica,sans-serif;max-width:520px;margin:0 auto;padding:24px;text-align:center;background:#ffffff;color:#111111">
  <h2 style="margin:0 0 16px;font-size:20px">استعادة كلمة المرور — Password Reset</h2>
  <p style="margin:0 0 16px;font-size:15px;line-height:1.6">استخدم رمز الأرقام الستة التالي لتعيين كلمة مرور جديدة:<br>Use this six-digit code to set a new password:</p>
  <div style="margin:16px 0;font-size:34px;font-weight:700;letter-spacing:10px">{{ .Token }}</div>
  <p style="margin:0 0 20px;font-size:13px;color:#666666;line-height:1.6">الرمز صالح لمدة ساعة ويعمل من أي جهاز أو متصفح.<br>The code is valid for one hour and works from any device or browser.</p>
  <p style="margin:0 0 24px"><a href="{{ .ConfirmationURL }}" style="display:inline-block;padding:12px 28px;background:#111111;color:#ffffff;border-radius:10px;text-decoration:none;font-size:14px">أو اضغط هنا لإعادة التعيين مباشرة — Or click here</a></p>
  <p style="margin:0;font-size:12px;color:#999999;line-height:1.6">إن لم تطلب هذا الرمز فتجاهل الرسالة وستبقى كلمة مرورك كما هي.<br>If you didn't request this, ignore this email — your password stays unchanged.</p>

```

القالب يحتفظ بزر الرابط `{{ .ConfirmationURL }}` — **الذراعان تعملان معًا**: من يفتح الرابط من نفس المتصفح يُقبض على المسار القديم، ومن لا يعمل معه الرابط يقرأ الرمز ويكتبه.

**بديل بيد الجلسة:** زوّدني بمفتاح Supabase شخصي (`sbp_…` من لوحة حساب Supabase → Access Tokens) وسأطبّق القالب برمجيًا عبر Management API وأتحقق منه بالقراءة العكسية — لكن اللصق اليدوي أسرع.

## 3. ما نُفذ في الكود (منشور ومتحقق حيًا)

| المكوّن | المنفذ |
|---|---|
| `/auth/reset` | آلة حالات ثلاثية: **failure** (هبوط رابط فاشل) · **code** (جديد: بريد + رمز، قابل للربط `?mode=code&email=`) · **form** (تعيين كلمة المرور — نفس الشاشة تُخدم مساري الرابط والرمز بعد نجاح التحقق) |
| نقاط الدخول للرمز | CTA في حالة الفشل («يعمل من أي جهاز») · رابط في نموذج كلمة المرور («الرابط لا يعمل أو على جهاز آخر؟») · زر «لديك رمز في البريد؟ أدخله هنا» في شاشة «أرسلنا رابط الاستعادة» مع تعبئة البريد مسبقًا |
| `src/lib/recovery-otp.ts` | تطبيع الإدخال: الأرقام العربية ٠-٩ والشرقية ۰-۹ ← ASCII، إسقاط المسافات/الشرطات، ورفض أي إدخال ليس ستة أرقام قبل نداء verifyOtp (+11 اختبارًا) |
| `error-i18n.ts` | رسايل فشل الرمز تنضم لقانون M1 — **اكتشاف حي**: رسالة gotrue الفعلية «Token has expired or is invalid» (مثبتة بمتصفح حقيقي) تختلف عن الموثقة «Email OTP has expired or is invalid» — كلتاهما مدمجتان |

**البوابات:** tsc صفر · eslint صفر · vitest ‏1579 اختبارًا · next build ✓ · صفر ميجريشن · صفر متغير بيئة جديد.

## 4. التحقق الحي المنفذ (على الإنتاج)

1. `/auth/reset?mode=code&email=…` → شاشة الرمز تُرى والبريد معبأ (EN) ✓
2. **كود خاطئ EN** ← نداء gotrue حقيقي ← «Token has expired or is invalid» حرفية (قانون EN) ✓
3. **كود خاطئ بالأرقام العربية ١٢٣٤٥٦ في الواجهة العربية** ← التطبيع يعمل ← الرسالة العربية الصادقة: «رمز الاستعادة غير صحيح أو انتهت صلاحيته — تأكد من الأرقام الستة، أو أعد إرسال رمز جديد.» ✓
4. حالة الفشل ← CTA «أدخل رمز الاستعادة من بريدك» ← شاشة الرمز ✓

**حد المنهج:** نجاح المسار الكامل (رمز صحيح ← جلسة ← كلمة مرور جديدة ← داشبورد) يتطلب رمزًا حقيقيًا من صندوق بريد — يُختبر لحظة لصق المالك للقالب بطلب استعادة فعلي وإدخال الرمز (نفس نمط I-2/H1: نقرة البريد بيد المالك).

## 5. إعادة اختبار المالك بعد لصق القالب

1. اطلب استعادة كلمة المرور من أي متصفح.
2. افتح البريد — ستجد رمزًا من 6 أرقام (وزر الرابط للطريق القديم).
3. من **أي جهاز** (حتى جوال مختلف تمامًا): `/auth/reset?mode=code` — أو من شاشة «أرسلنا رابط الاستعادة» اضغط «لديك رمز في البريد؟ أدخله هنا».
4. أدخل بريدك والرمز ← عيّن كلمة المرور ← تُحوَّل للداشبورد مسجلًا.
