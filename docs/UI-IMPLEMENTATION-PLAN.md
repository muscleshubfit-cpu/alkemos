## 1. الدفعات (ترتيب التنفيذ الملزم)

### الدفعة 1 — Critical (هذه المرحلة: 198)
1. **C1:** زرا الـHero — `.btn-chrome` «Start Free / ابدأ مجانًا» → `/memberships` (بالمتغير AR) + زر ثانوي شفاف بخلفية كارت شبه صلبة «Explore Free Tools / استكشف الأدوات المجانية» → `#tools`. مقاس واحد أصغر (px-5 py-2.5 text-sm). تحت سطر الوصف وقبل الأختام.
2. **C4:** `.hero-copy` في globals.css — text-shadow مزدوج بمتغيرات الثيم لعناصر نص الـHero (H1 + الوصف).
3. **C3:** سلّم `.chrome-text` الفاتح → فولاذ داكن (أفتح نقطة ‎≥9:1‎)؛ الداكن كما هو. + `.hero-seals .seal-chip` خلفية أكثر صلابة (85%) فوق العمل الفني.
4. **C2:** كل أقسام محتوى الرئيسية (evo/tools/exercises/programs/foods/blog/coaching/featured-coaches/for-coaches/memberships/affiliate/faq-wrapper/cta/newsletter) → حاوية `mx-auto w-full max-w-6xl px-4` (النصوص الداخلية المركزية تبقى بحد قرائها).
5. **C5:** إعادة إنتاج شكوى الـheader بصريًا على البناء المحلي — إصلاح فقط إن تكررت، وإلا تُغلق موثقة.

**قبول الدفعة 1:** CTA ظاهر بالسياقات الخمسة ومقصوص الزيارة صحيحًا · تباين الأرقام الكرومية الفاتحة ‎≥4.5:1‎ (فحص محسوب) · حواف الكروت الرأسية متطابقة بين الأقسام على 1440 · صفر overflow · البوابات خضراء (tsc/eslint/vitest/build/stale-refs) · لقطات قبل/بعد.

### الدفعة 2 — High (المرحلة 199)
1. **H1:** توحيد الكروت — default: `marble-card` · featured: بطاقة داكنة `#0B0B0D` بحلقة كروم 2px. تحويل: شريط المدربين (M11) وكروت ميزات الكوتشينج وغيرها.
2. **H2:** دمج Latest+Featured في قسم واحد بكاروسيل واحد — المقالات المميزة كروت داكنة أول الصف + عنوان قسم واحد + «View all ›».
3. **H5:** تنحيف كارت EVO (min-height 280→220 / 340→260 + py القسم 16/24→12/16) — بقاء البطاقة المستقلة والوصفة.
4. **H6:** كارت Free ثالث (صف 3 أعمدة md: Free/Premium/Pro مع إبراز Pro) + جدول المقارنة داخل Accordion افتراضيًا مغلق.
5. **M10 + M8 + M11:** pill أزرق→seal-chip داكن · أختام الأفلييت بصف الشريط · شريط المدربين marble-card بظل أحادي.

**قبول الدفعة 2:** نمطا كروت فقط في DOM الرئيسي · قسم المدونة بنصف ارتفاعه السابق تقريبًا · قسم Pricing بثلاثة كروت متساوية الارتفاع وجدول مطوي · صفر أزرق خارج `--ai` (grep) · السياقات الخمسة + بوابات خضراء.

### الدفعة 3 — Polish (المرحلة 200)
1. **Mobile:** chips التنقل صف أفقي واحد scroll-snap (H4/M-mobile) · أسهم الكاروسيل 36px · فحص الهامبرجر/Drawer z-index.
2. **Tablet:** شبكة التمارين 3 أعمدة عند md وسلم H2 موحد.
3. **M1/M2/M3:** مقياس أزرار (40/48/56) · H3 موحّد text-lg · محاذاة عناوين center موحدة.
4. **M4/M7/M9:** سطر مستويات بكروت العضلات · إصلاح عرض input النشرة · تمرير alt للصور المحتوى-only.
5. **H7:** إعادة إنتاج قص أول كارت بـ‎/ar‏ وإصلاح منطق اتجاه التمرير.

**قبول الدفعة 3:** chips الجوال ≤ ‎~60px‏ ارتفاعًا · توحيد المقاييس بالفحص الكمي (سكربت القياسات) · ‎/ar‏ كاروسيل بلا قص · السياقات الخمسة + بوابات خضراء.

## 2. ما لا يُمس (ثوابت ملزمة)

- هوية Marble & Chrome وتوكنزها وطباعة Playfair/Cairo الحالية (قرار §16).
- أزرار/shارات EVO: البطاقة المستقلة بلا وصف وأزرار (127/128/131) — تنحيف فقط.
- رسائل النسخ المعتمدة (193-197): لا كلمة تسويقية تُبدَّل.
- الأسعار والحدود والـentitlements والـrouting والـschema/JSON-LD والـSEO metadata.
- كارت «Your plan. Built for you.» وCTA «Create My Plan» (عقود اختبارات المولّدين).
- فقاعة EVO العائمة كنقطة دخول الدردشة (أمر مالك موثق).
- الشريحة الممتلئة «Memberships» في chips التنقل (قرار 2026-08-30).

## 3. بروتوكول الاختبار لكل دفعة (5 سياقات + بوابات)

1. `bunx tsc --noEmit` · `bun run lint` · `bun run test` · `bun run build` · `bash scripts/check-stale-refs.sh`.
2. Playwright محليًا (dev server): Desktop 1440 / Tablet 768 / Mobile 375 / Dark 1440+375 / ‎/ar‏ 1440+375 — لقطات كاملة + فحص overflow أفقي + قياس أطوال الأقسام قبل/بعد.
3. التحقق البصري المستهدف لكل بند معدّل (قبل/بعد).
4. بعد الـpush: تحقق حي على الإنتاج بنفس السياقات (نمط §3.7) قبل إعلان إغلاق الدفعة.
