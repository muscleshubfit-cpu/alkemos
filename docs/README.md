## How to keep this registry true

1. **New doc lands → new row in the same commit** (name it in the commit body too). Point-in-time reports (audits/plans/execution logs) are **BORN ARCHIVED** — they land directly in `docs/archive/` with their row here (Ph 291 law, audit P3-1: the live `docs/` surface is active reference only).
2. **Point-in-time docs** (audits/plans) get their status flipped to EXECUTED when their findings land, with the closing phase numbers.
3. **Dates are NOT hand-maintained** (Ph 289): git is the single source — `scripts/docs_audit.py` check M verifies this table bidirectionally on every push (paths exist · every `docs/*.md` registered) and its REPORT derives each file's last-commit date. No column, no bumping, no fix-up commits.
4. A doc that stops being cited anywhere and describes nothing live is FROZEN-to-archive material (§3.8) — move it, don't delete history.
