# EVO Partner API — العقد الرسمي للشركاء (EVO-6 / W6)

> **الحالة:** منفذ (المرحلة 169) بأمر المالك «ابدأ evo 6» — التفعيل العلني يتطلب علم البيئة `EVO_PARTNER_API_ENABLED=true`.
> **القانون الحاكم:** AGENTS.md «EVO-6 PARTNER API LAW» + ميجريشن 0082 + docs/EVO-MASTER-PLAN.md §4 W6.
> **لغة العقد:** عربي مع مصطلحات إنجليزية للأسماء التقنية — الشركاء الدوليون يقرؤون نفس الأقسام بالإنجليزية أدناه.

---

## 1. ماذا يقدم هذا الـAPI؟

واجهة برمجية عامة تتيح لشركاء Alkemos (مواقع صحية، تطبيقات جيم، مدربون، مجتمعات رياضية) إضافة **مدرب EVO الذكي** لجمهورهم: محادثة لياقة وتغذية بالعربية والإنجليزية، بنفس شخصية المدرب ونفس دروع السلامة المستخدمة داخل alkemos.com، عبر سطر تضمين واحد أو نداء HTTP مباشر.

نطاق v1 **محادثة عامة فقط** بوعي كامل: لا خطط تغذية أو تدريب (سطوح المشتركين داخل المنصة)، لا سياق شخصي، لا ذاكرة — حماية للتكلفة ولفعوية الإساءة وخصوصية مستخدمي الشريك.

## 2. المصادقة والمفاتيح

- كل شريك يحصل على مفتاح بالصيغة `pk_live_` + 32 محرفًا hex (إجمالي 40).
- المفتاح الخام **يُعرض مرة واحدة** لحظة الإنشاء من لوحة الأدمن `/admin/evo-partners` ويُخزن **هاش SHA-256 فقط** — لا يمكن استرجاعه لاحقًا، والدوران (rotation) = إنشاء مفتاح جديد + إيقاف القديم.
- الإيقاف دائمًا `UPDATE is_active=false` — لا مسار حذف (قانون «الإيقاف UPDATE لا delete»).
- تمرير المفتاح: `Authorization: Bearer pk_live_…` (الأولى) أو `x-api-key: pk_live_…`.

## 3. نقطة النهاية

### `POST /api/evo/v1/chat`

**الطلب:**
```json
{
  "message": "ما هو أفضل تمرين لبناء الصدر؟",     // مطلوب · ≤ 2000 محرف
  "history": [                                     // اختياري · آخر 8 أدوار كحد أقصى
    { "role": "user", "content": "…" },
    { "role": "assistant", "content": "…" }
  ],
  "language": "ar"                                 // اختياري — الافتراضي كشف آلي من النص
}
```

**الاستجابة الناجحة (200):**
```json
{
  "reply": "…نص الرد النهائي…",     // نص عادي — بلا Markdown ولا LaTeX
  "source": "groq:llama-…",         // أو cache:… · safety
  "provider": "groq",               // openrouter | groq | nvidia | cache | safety
  "cached": false                   // true = جاء من كاش الأسئلة الشائعة
}
```

**الأخطاء:**

| الكود | error | المعنى |
|---|---|---|
| 404 | `not-found` | العلم `EVO_PARTNER_API_ENABLED` مطفأ |
| 401 | `unauthorized` | مفتاح مفقود/غير صحيح/موقوف |
| 400 | `unsupported-intent` | طلب خطة أو استبدال — خارج نطاق v1 |
| 400 | (رسالة وصفية) | شكل الطلب خاطئ (طول/أدوار/لغة) |
| 429 | `rate_limited` | 30 طلب/دقيقة كحد أقصى لكل مفتاح+IP |
| 429 | `quota_exceeded` | استُهلكت الحصة الشهرية |
| 503 | `upstream-unavailable` | مزودو النماذج تعذروا — أعد المحاولة |

## 4. الحصص والقياس

- **الحصة الشهرية:** عدد الرسائل المخدومة بنجاح خلال شهر UTC الحالي (`evo_api_usage` صفوف `success`) — تُضبط لكل مفتاح من الأدمن (افتراضي 1000).
- **سجل القياس:** صف لكل محاولة طلب بحالتها النهائية (`success` / `rate_limited` / `quota_exceeded` / `rejected` / `error`) — بما فيها المحاولات المرفوضة، كسجل تدقيق للإساءة. صف `success` يُكتب **قبل** إرجاع الاستجابة (سلامة الحصة).
- **الكاش:** أول رسالة في المحادثة (بدون تاريخ) قد تُخدم من كاش الأسئلة الشائعة نفسه المستخدم داخل المنصة — وتُحسب من الحصة كأي رسالة (الكاش يوفر تكلفة المزود لا حصة الشريك).

## 5. التضمين بسطر واحد

```html
<script src="https://alkemos.com/embed/evo.js" data-key="pk_live_…"></script>
```

- يحقن زرًا عائمًا + **iframe معزولًا** على `/embed/widget` (عزل كامل عن CSS/JS صفحة الشريك).
- خصائص اختيارية: `data-side="left"` (الزر يسار الصفحة).
- اللغة تُكشف تلقائيًا من لغة متصفح الزائر، وثيم الشريك (لون/شعار/ترحيب) يُصيَّر من الخادم بعد التحقق من المفتاح.
- المفتاح في سطر التضمين **علوي أمام شريكه نفسه** بطبيعته (يستخدمه من طرفه) — الحماية الحقيقية: الحصص + القياس + الإيقاف الفوري من الأدمن.

## 6. الثيم الأبيض (white-label)

يُدار من `/admin/evo-partners` ويُخزن في `evo_api_keys.theme` بعد تمرير إلزامي عبر `validatePartnerTheme` (قائمة بيضاء):

| الحقل | القيد |
|---|---|
| `accent` | لون `#hex` (3 أو 6 أرقام) — أزرار وفقاعات المستخدم |
| `logo_url` | رابط `https` فقط ≤ 500 محرف |
| `greeting_ar` / `greeting_en` | نص ≤ 300 محرف (رسالة الترحيب) |
| `partner_label` | نص ≤ 60 محرفًا (يظهر تحت EVO) |

أي حقل آخر **يُهمَل**، وأي قيمة مخالفة **تُرفض** — الويدجت يستهلكها كمتغيرات CSS وبيانات نصية، فلا يمكن حقن أي markup.

## 7. الخصوصية وسلامة المحتوى

- لا حسابات ولا بيانات شخصية في هذا السطح: محادثة الشريك لا تُخزن، ولا ذاكرة، ولا PII لأي وجهة جديدة.
- درع الأزمة (YMYL) مطبق على كل رسالة: إشارات اضطراب الأكل/الإيذاء تحصل على رد آمن ثابت بتوجيه لمساعدة بشرية/طبية.
- إجابات المزود تمر بنفس منظفات المسار الرئيسي (إزالة كتل التفكير + LaTeX + Markdown) — ما يراه مستخدم الشريك مطابق لما يراه مستخدم المنصة.

## 8. شروط الاستخدام للشريك (تُقبل بطلب المفتاح)

1. استخدام المفتاح في محتوى لياقة/صحة محترم فقط — لا إعادة توزيع للمفتاح لطرف ثالث دون علم Alkemos.
2. الالتزام بسقف الحصة والـrate limit؛ تجاوز المتعمد = إيقاف المفتاح.
3. منع تقديم الـAPI لمستخدمي المنصة كبديل مباشر عن سطحها الداخلي (لا وصول لسطوح المشتركين).
4. النص الصادر من EVO إرشادي عام وليس نصيحة طبية — يلتزم الشريك بإبقاء أي تنويه صحي يقدمه EVO كما هو.
5. Alkemos يحق له تعديل الحصص أو إيقاف أي مفتاح مخالف بإشعار من الأدمن.

## 9. المصفوفة التشغيلية للأدمن

| الفعل | من أين | ملاحظة |
|---|---|---|
| إنشاء مفتاح | `/admin/evo-partners` → «مفتاح جديد» | الخام يظهر مرة واحدة |
| إيقاف/تفعيل | زر الإيقاف بكارت الشريك | فوري (kill switch) |
| تعديل الحصة/الثيم | نفس الكارت | تحقق خادمي بالكامل |
| مراقبة الاستهلاك | عداد الشهر + 30 يومًا لكل كارت | من سجل `evo_api_usage` |
| تدقيق الإساءة | صفوف `rejected/rate_limited` في السجل | تُغذي /admin/evo-analytics لاحقًا |
| تحليلات الجودة | `/admin/evo-analytics` | صفوف `evo_call_stats` تشمل نداءات الشركاء |

## — English Quick Reference —

**Auth:** `Authorization: Bearer pk_live_…` (or `x-api-key`). **Endpoint:** `POST /api/evo/v1/chat` with `{ message (≤2000), history (≤8 turns), language ("ar"|"en") }` → `{ reply, source, provider, cached }`. General fitness/nutrition conversation only — plan/swap intents return 400. Rate limit 30 req/min per key+IP; monthly quota counts successful replies (UTC month). Crisis-detection shield is always active; replies are plain text. Embed: one `<script>` line (see §5) → isolated iframe chat with white-label theming. Keys are shown once, stored hashed (SHA-256), revocable instantly. Full terms: §8.
