# STAFF-BELL-I18N-251 — جرس الطاقم يتكلم لغة المشاهد + مسح المشاكل المشابهة (جرس العضو)

**التاريخ:** 2026-09-22 · **الأمر الملكي:** «ابدأ الخطوه التالية المقترحة ترجمة نصوص جرس الطاقم ثم ابحث عن اى مشاكل مشابهة لحلها»

---

## 1) الخلفية

المرحلة 250 (NOTIF-I18N-250) أقامت قانون «الإشعارات تتكلم لغة المستخدم» على **جرس العضو** للأنواع
النظامية الخمسة المستقرة، ووثّقت صدقًا في §4 حدّها: **جرس الطاقم** (admin_notifications — الجرس
المشترك بين الأدمن والمدربين) بقي محتواه نصوصًا عربية خامًا من ~20 موضع إنشاء متعدد الأدوار —
عضو/أدمن بواجهة إنجليزية يقرأ عربيًا. هذه المرحلة تغلق الفجوة على **الجرسين معًا**.

**صفر ميجريشن:** عمود `payload jsonb default '{}'` موجود على الجدولين منذ 0093.

## 2) الموجة الأولى — كتالوج جرس الطاقم (19 نوعًا)

`lib/notification-i18n.ts` — `ADMIN_CATALOG` + `localizeAdminNotification(row, lang)`:

- **قانون اللاحقة:** ثلاثة مواضع تُلحق لاحقة إزالة تكرار بالنوع (`coach_page_pending:{uid}` ·
  `refund_request:{uid}:{date}` · `subscription_cancel_request:{uid}:{date}`) — المطابقة على
  النوع الأساسي (قبل أول `:`).
- **قانون UGC:** ما هو كلام مستخدم يبقى حرفيًا داخل القالب المترجم — موضوع تذكرة المدرب، نص رد
  الدعم، سبب الرفض الملكي، سبب عكس العمولة. نترجم القالب لا كلام الناس.
- **قانون الفولباك الصادق (على مستوى المُدخل):** سطر بلا payload (أو بحقل مطلوب ناقص) يُعرض
  حرفيًا كما خُزّن — الصفوف القديمة لا تُخمَّن ولا تُمس.
- **قانون المال:** `$` تبقى لاتينية، والأرقام تتكلم لغة الواجهة (ar-EG هندية).
- **قانون الجمع العربي:** arMonthsPhrase يملك «شهر واحد/شهرين/أشهر/شهرًا» — يصلح حيًا أخطاء
  «لمدة 1 شهر» الموروثة في نصوص الـ fallback فقط (النصوص الجديدة من الكتالوج سليمة).
- **وسم الآلة:** جسم `payout_request` القديم يحمل `[uid:…]` لإزالة التكرار (فلتر ilike يقرأ
  قاعدة البيانات لا العرض) — عرض الكتالوج يسقط الوسم، والفولباك يبقيه حرفيًا (صدق).

### قناة الـ payload (عميل → سيرفر)

1. `createAdminNotification(type, title, body, link?, clientId?, **payload?**)` تمرره في جسم POST.
2. `adminNotificationBodySchema` يقبل `payload: record(string, unknown).optional()`.
3. مسار POST يُطهّره (`sanitizePayload`: JSON ≤ 2000 حرف وإلا `{}` — الحد يمنع الإساءة، والعرض
   يقرأ حقول محددة فقط عبر React المهرِّب) ثم يخزنه.
4. مواضع العميل الخمسة (auth ×4، questionnaires، subscriptions، tickets، plans) ومواضع السيرفر
   (paypal capture، support/tickets، coach/landing، coach/ads، coach/register ×3، coach-pages
   rejected، refund/request، subscription/cancel، payout-notify، affiliate-engine ×2) تمرر حقولًا
   مهيكلة. المواضع الساكنة (coach/support، coach-pages/notify، welcome/setup/approved) لا تحتاج.

### العرض

`AdminNotificationBell` يعرض عبر `localizeAdminNotification(n, lang)` — لغة **المشاهد** (الأدمن
والمدرب يقرأ كلٌّ بلغته من نفس الصف). التوقيت كان مكتملًا من 250.

## 3) الموجة الثانية — مسح المشاكل المشابهة: 12 نوع عضو خارج كتالوج 250

مسح كل مواضع `notifications` و`createNotification` كشف أنواعًا نظامية تكتب عربيًا خامًا منذ قبل
250 (لم تدخل كتالوج العضو). أُضيفت لنفس `CATALOG` بقانون المواضع نفسه:

| النوع | مواضع الإنشاء | payload |
|---|---|---|
| referral_commission | affiliate-engine (عضو) + referral.ts (إحالة صديق) | amount_usd, source(+friend_referral) |
| referral_commission_reversed | affiliate-engine (عضو) | amount_usd, reason |
| payout_paid / payout_rejected | referral.ts | amount_usd (+note) |
| refund_approved / refund_rejected | admin/refunds | amount_usd+ended · note |
| wallet_adjusted | admin/wallets/adjust | amount, note |
| wallet_topup_approved | topups (manual) + paypal capture | amount, balance, provider |
| wallet_topup_rejected | topups | amount, note |
| coach_ad_started | coach/ads (عضو) | pkg_ar/pkg_en, ends_iso |
| coach_support_reply / support_reply | admin/coach-support + support/tickets | — (عنوان فقط؛ المتن UGC حرفي) |

**الخارج عن القانون عمدًا:** `coach_message` (بث المدرب) — عنوانه ومتنه كلام المرسل كليًا (UGC
خالص)، فالفولباك الحرفي هو الصواب له، ولا كتالوج له.

## 4) حدود الفريم (صدق)

- الصفوف القديمة (بلا payload) تعرض حرفيًا عربيًا كما خُزّت — القانون الصادق؛ تتحسن لغةً فقط
  للإشعارات الجديدة من لحظة النشر. التواريخ كانت مكتملة من 250.
- عناوين مواضع LS التجريبية (createAdmin fallback المحلي) تبقى حرفية — مسار ديمو فقط.
- إثبات الحي E2E (بثّ عميل/مدرب/أدمن حقيقي وقراءة الجرسين باللغتين) = مدخل LIVE-VERIF مستقل بعد
  اكتمال النشر، بنمط 246–250.

## 5) خطوات تحقق المالك (بعد النشر ~3 دقائق)

1. حسابك بواجهة **إنجليزية** → أي حدث (طلب دفع/تذكرة/تسجيل عميل) → جرس الطاقم يعرض العنوان
   والمتن إنجليزيًا («New payment request — Ahmad requested the Premium plan for 2 months — $18.»).
2. حوّل الواجهة للعربية → نفس الصف تُعرض بنحو عربي سليم («لمدة شهرين» لا «2 شهر»).
3. شاشة الصرف (`/admin/referrals`) أو الاسترداد → الجرس بلا وسم `[uid:…]`.
4. صفوف قديمة (قبل اليوم) تبقى كما هي حرفيًا — هذا مقصود (قانون الصدق).
