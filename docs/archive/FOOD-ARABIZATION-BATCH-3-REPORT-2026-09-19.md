# Food Data Arabization — Batch 3 Execution Report
## The owner-ordered third batch (+953 USDA foods) — 2026-09-19

> **الغرض:** توثيق تنفيذ الدفعة الثالثة من خطة تعريب الأطعمة المعتمدة `docs/FOOD-DATA-ARABIZATION-PLAN-2026-09-19.md` (الخطة §8 Phase 2: دفعات 500–1,000 متتالية بأمر مالك) — التنفيذ بأمر مالك صريح 2026-09-19 «ابدأ دفعة ٣»، بنفس قوانين الدفعتين السابقتين حرفيًا: تعريب `nameAr` فقط بفصحى معيارية، بلا لمس slug/nameEn/الأرقام/category، بلا تعبئة tags، وبلا أي تغيير لسياسة sitemap/indexing.

## 1. الملخص التنفيذي

نُفّذت الدفعة الثالثة كاملة: **953 صنف USDA** إضافي حصل على `nameAr` عربية فصحى (ضمن نطاق 500–1,000 المأمور)، عبر نفس خط الإنتاج fail-closed بسابقة Phase 191 مع امتداد جديد: **dedupe دلالي لقطع اللحوم** (ممثل واحد لكل قطعة×جزء×تجهيز، مع إسقاط ضوضاء الدرجات/التشذيب/المنشأ — عكس الترجمة الحرفية لمتغيرات USDA شبه المتطابقة التي حذرت منها الخطة §3.5). النطاق التراكمي `SEO_FOOD_BAND` أصبح **2,409 أصناف** (481 + 975 + 953) — كل صفحاتها العربية انقلبت `index,follow` تلقائيًا عبر regex `arabiclessName` القائم، وصفر تغيير في أي مسار أو سياسة. الوصول العربي لـEVO قفز من 17.4% إلى **28.2%** من قاعدة البيانات (2,489/8,830 = 80 منسّق + 2,409 نطاق)، ووصول البحث العربي كذلك.

### 2.2 الأثر التلقائي (بلا أي تغيير مسارات)
1. **قابلية الفهرسة:** 953 صفحة `/ar/foods/<slug>` إضافية انقلبت `noindex,follow` → `index,follow` — الصفحات العربية القابلة للفهرسة الآن **2,489** (80 منسّقًا + 2,409 نطاق)، والتوأم الإنجليزي كما هو (سياسة Phase 141: 8,830 صفحة قابلة للفهرسة غير معلنة).
2. **JSON-LD عربي:** عناوين NutritionInformation/Breadcrumb للدفعة عربية الآن (GEO).
3. **EVO والبحث العربي:** الاستعلام العربي يصل الآن **2,489/8,830 = 28.2%** (كان 17.4% بعد الدفعة الثانية، 6.4% بعد الـPilot، 0.9% قبله) — لحوم الدواجن والقطعات والشوربات والزبادي اليوناني ضمن أعلى استعلامات اللياقة العربية.
4. **بطاقات القوائم العربية:** صفحات `/ar/foods` العميقة تعرض أسماء عربية لأصناف الدفعة.

## 3. ما لم يتغير (قيود المالك مطبقة حرفيًا)

- **sitemap-foods.xml لم يُمس**: المعيار يظل `tags.length > 0` حصرًا (160 URL) — كاناري PILOT-HOLD يحرسه. ربط النطاق بمعيار sitemap المركّب يبقى فريمًا مستقلًا بقرار مالك بعد أدلة GSC.
- **tags فارغة لكل صفوف الدفعة** — إشارة التنسيق اليدوي حصرًا (يحرسها الحارس 1).
- **الـ80 منسّقًا بلا أي تعديل** (هاش المنسّقين `e12bcb26…` متطابق قبل/بعد — يتحقق الاختبار 2 وسكربت الحقن).
- **الـ8,830 slug بلا أي تغيير** (عضوية وترتيب — هاش `0b2c0ac2…` متطابق — يتحقق الاختبار 3).
- **nameEn مجمّد لكل صفوف النطاق** (هاش جديد مثبت على العضوية التراكمية 2,409: `d0b5b15d…` — يتحقق الاختبار 4).
- **defaultServingAr «100g» كما هي** · **EVO صفر تغيير** · **?lang كما هو** (عقد المرحلة 0).
